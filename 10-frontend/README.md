# 10 · Frontend moderno

Esta etapa comienza después de dominar HTML, CSS, JavaScript del navegador y consumo básico de datos. Su objetivo es aprender a construir interfaces mediante componentes sin perder de vista los fundamentos de la plataforma web.

## Ruta disponible

1. `01-angular-fundamentos`: componentes standalone, interpolación, property binding, event binding, directivas, formularios y pipes.
2. `02-angular-servicios-http-y-apis`: servicios inyectables, `HttpClient`, observables, APIs, formularios y estados de carga o error.
3. `03-react-fundamentos`: componentes, JSX, estado, eventos, listas y formularios controlados.
4. `04-react-enrutamiento-y-formularios`: React Router, composición, rutas y formularios con retroalimentación accesible.
5. `05-react-consumo-de-apis`: solicitudes remotas, Alova y estados asíncronos.
6. `06-react-integracion-interactiva`: práctica completa con efectos, audio, teclado, gestos y accesibilidad.

Los siguientes módulos se incorporarán cuando exista contenido propio, probado y suficiente. No se crean carpetas vacías para simular avance.

## Criterio de avance

Antes de continuar debes poder explicar cómo se divide una interfaz en componentes, cómo cambia a partir del estado, cómo se valida una entrada, cómo una URL selecciona una vista y por qué el acceso HTTP debe separarse de la presentación.
