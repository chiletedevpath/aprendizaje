# 10 · Frontend moderno

Esta etapa comienza después de dominar HTML, CSS, JavaScript del navegador y consumo básico de datos. Su objetivo es aprender a construir interfaces mediante componentes sin perder de vista los fundamentos de la plataforma web.

## Ruta disponible

1. `01-angular-fundamentos`: componentes standalone, interpolación, property binding, event binding, directivas, formularios y pipes.

Los siguientes módulos se incorporarán cuando exista contenido propio, probado y suficiente. No se crean carpetas vacías para simular avance.

## Criterio de avance

Antes de continuar debes poder explicar cómo se divide una interfaz en componentes, cómo fluye la información entre clase y plantilla, cómo se valida una entrada y cuándo conviene transformar datos con un pipe.

Contenido creado para Chilete DevPath con apoyo de IA para estructuración y revisión. El criterio, selección y validación final corresponden a Adrian Pisco, autor de Chilete DevPath.
