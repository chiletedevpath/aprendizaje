Chilete DevPath explica: el componente delega las peticiones al servicio. Un GET obtiene o filtra alumnos mediante HttpParams y un POST registra uno nuevo; el componente se suscribe al observable y comunica los estados de carga, vacío, éxito y error. Observa esos cambios al detener o iniciar json-server.
