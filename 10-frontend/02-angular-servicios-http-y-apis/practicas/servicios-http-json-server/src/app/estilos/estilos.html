Estilos interactivos

El botón modifica su color y también el estilo del texto.

Chilete DevPath explica: el evento (click) cambia el estado resaltado y [ngStyle] vuelve a calcular la apariencia a partir de ese estado. Observa que Angular actualiza la interfaz sin manipular el DOM manualmente.

Este texto cambia de apariencia al pulsar el botón.
