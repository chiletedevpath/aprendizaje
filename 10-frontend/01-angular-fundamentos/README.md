# 01 · Fundamentos de Angular

## Qué debes dominar

- componentes standalone y metadatos de `@Component`;
- interpolación y enlace de propiedades;
- eventos y actualización de estado;
- `NgClass` y `NgStyle` para presentación dinámica;
- componentes reutilizables;
- formularios dirigidos por plantilla;
- validación básica;
- pipes propios y pruebas unitarias.

## Prácticas

- `practicas/perfil-y-estilos-dinamicos`: componente de perfil con interpolación, `NgClass`, `NgStyle` y respuesta a eventos.
- `practicas/componentes-pipes-y-formularios`: composición de componentes, formulario validado y pipe de conversión monetaria.

## Reto

Extrae la ficha del perfil a un componente reutilizable y recibe sus datos mediante entradas. Después, agrega una salida que notifique al componente padre cuando cambie el modo de presentación.

## Para avanzar

Debes poder ejecutar ambas prácticas, describir el ciclo clase–plantilla–evento y modificar los datos sin romper las pruebas ni la compilación.
