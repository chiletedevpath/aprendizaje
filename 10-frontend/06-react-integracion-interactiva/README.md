# 06 · Integración interactiva con React

Este bloque reúne componentes, estado, efectos, eventos de teclado y táctiles, audio y accesibilidad en una experiencia completa. El objetivo no es copiar una plantilla: es reconocer cómo colaboran las piezas y adaptar el contenido con criterio.

## Práctica

`practicas/carta-cumpleanos-interactiva` es una carta genérica de cumpleaños dividida en escenas. Los textos se separan en un módulo de datos y los recursos de demostración son locales.

La interfaz incluye una explicación desplegable de los conceptos aplicados y una identificación discreta de Chilete DevPath.

## Antes de publicar una adaptación

- sustituye textos e imágenes de demostración;
- confirma que tienes permiso para publicar fotografías y audio;
- no presentes una URL pública como privada;
- comprueba teclado, pantalla pequeña y preferencia de movimiento reducido.

## Reto

Extrae una escena nueva a su propio componente y conserva la navegación, el foco y los controles de teclado.

Contenido adaptado para Chilete DevPath con apoyo de IA para estructuración y revisión. El criterio, selección y validación final corresponden a Adrian Pisco, autor de Chilete DevPath.
