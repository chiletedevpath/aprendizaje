# 03 · Fundamentos de React

React organiza la interfaz en componentes y vuelve a renderizarla cuando cambia su estado. Este bloque conecta los fundamentos de JavaScript con JSX, propiedades, eventos y actualizaciones inmutables.

## Qué debes dominar

- componentes funcionales y JSX;
- propiedades y composición;
- estado con `useState`;
- formularios controlados;
- renderizado de listas y claves estables;
- eventos y actualización inmutable de colecciones.

## Práctica

`practicas/lista-tareas` permite agregar, completar y eliminar tareas. La propia interfaz explica qué parte corresponde al estado, al formulario controlado y al renderizado con `map`.

Para ejecutarla, entra en la carpeta de la práctica y usa `npm ci` seguido de `npm run dev`.

## Reto

Añade filtros para mostrar todas, pendientes o completadas sin guardar una segunda lista en el estado.
