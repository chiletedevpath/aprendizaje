# 04 · Enrutamiento y formularios con React

Una aplicación de una sola página puede cambiar de vista sin recargar el documento. El enrutador relaciona URL y componente; los formularios controlados mantienen sus valores en el estado de React.

## Qué debes dominar

- rutas, enlaces y ruta no encontrada;
- componentes de estructura compartida;
- propiedades entre componentes;
- listas obtenidas desde módulos de datos;
- formularios controlados y manejo de `submit`;
- retroalimentación accesible sin usar ventanas `alert`.

## Práctica

`practicas/portal-educativo` integra navegación con React Router, componentes reutilizables, tablas generadas con `map` y un formulario controlado de demostración.

## Reto

Agrega una ruta de detalle para cada curso y permite acceder a ella desde el listado mediante un parámetro de URL.
