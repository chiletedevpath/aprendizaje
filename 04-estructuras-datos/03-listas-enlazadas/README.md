# 03 · Listas enlazadas

**Nivel:** Básico

**Objetivo:** Comprender nodos, referencias y enlaces simples o dobles, además de comparar listas enlazadas con listas basadas en arreglo.

## Qué debes comprender

- nodo
- referencia siguiente/anterior
- lista simple
- lista doble
- comparación con ArrayList

## Cómo trabajar el tema

1. Revisa `java/ejemplos` o `scala/ejemplos` para observar el uso mínimo.
2. Cuando exista `implementaciones/`, léela para entender cómo se construye la estructura.
3. Revisa las prácticas completas.
4. Resuelve el reto sin abrir `soluciones/`.
5. Compara tu decisión y prueba casos límite.

## Reto

Implementa una lista enlazada de tareas que permita agregar al final, eliminar por código y recorrer todos los nodos.

## Para avanzar

Debes poder explicar **por qué esta estructura es adecuada**, no solo escribir su sintaxis.
