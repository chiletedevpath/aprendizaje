# 13 · Selección y combinación de estructuras

**Nivel:** Intermedio

**Objetivo:** Elegir y combinar estructuras a partir de las operaciones requeridas, justificando costos, restricciones y claridad del modelo.

## Qué debes comprender

- operación dominante
- orden
- duplicados
- búsqueda por clave
- prioridad
- combinación List/Set/Map/Queue

## Cómo trabajar el tema

1. Revisa `java/ejemplos` o `scala/ejemplos` para observar el uso mínimo.
2. Cuando exista `implementaciones/`, léela para entender cómo se construye la estructura.
3. Revisa las prácticas completas.
4. Resuelve el reto sin abrir `soluciones/`.
5. Compara tu decisión y prueba casos límite.

## Reto

Diseña las estructuras para un sistema de cursos: orden de inscripción, búsqueda por DNI, cursos únicos y alertas por prioridad. Justifica cada elección.

## Para avanzar

Debes poder explicar **por qué esta estructura es adecuada**, no solo escribir su sintaxis.
