# 02 · Arreglos y listas dinámicas

**Nivel:** Básico

**Objetivo:** Comparar almacenamiento contiguo, tamaño fijo y crecimiento dinámico usando arreglos, ArrayList y estructuras equivalentes.

## Qué debes comprender

- arreglo fijo
- lista dinámica
- tamaño y capacidad
- acceso por índice
- costo de inserciones

## Cómo trabajar el tema

1. Revisa `java/ejemplos` o `scala/ejemplos` para observar el uso mínimo.
2. Cuando exista `implementaciones/`, léela para entender cómo se construye la estructura.
3. Revisa las prácticas completas.
4. Resuelve el reto sin abrir `soluciones/`.
5. Compara tu decisión y prueba casos límite.

## Reto

Construye un registro de temperaturas que permita consultar por posición, agregar datos y eliminar una posición. Explica qué operaciones pueden desplazar elementos.

## Para avanzar

Debes poder explicar **por qué esta estructura es adecuada**, no solo escribir su sintaxis.
