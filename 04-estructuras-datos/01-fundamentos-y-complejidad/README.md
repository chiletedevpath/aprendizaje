# 01 · Fundamentos y complejidad

**Nivel:** Básico

**Objetivo:** Comprender qué es una estructura de datos, qué operaciones ofrece y cómo interpretar costos O(1), O(log n), O(n) y O(n²).

## Qué debes comprender

- TAD y estructura concreta
- operaciones: acceso, inserción, eliminación y recorrido
- O(1), O(log n), O(n), O(n²)
- estructura estática y dinámica

## Cómo trabajar el tema

1. Revisa `java/ejemplos` o `scala/ejemplos` para observar el uso mínimo.
2. Cuando exista `implementaciones/`, léela para entender cómo se construye la estructura.
3. Revisa las prácticas completas.
4. Resuelve el reto sin abrir `soluciones/`.
5. Compara tu decisión y prueba casos límite.

## Reto

Compara tres operaciones sobre una colección y clasifica su costo aproximado. Justifica cada respuesta sin medir tiempos como única evidencia.

## Para avanzar

Debes poder explicar **por qué esta estructura es adecuada**, no solo escribir su sintaxis.
