# Checklist de avance

## Dominio técnico

- [ ] Distingo TAD de implementación concreta.
- [ ] Interpreto O(1), O(log n), O(n) y O(n²) a nivel práctico.
- [ ] Comparo arreglo, lista dinámica y lista enlazada.
- [ ] Uso pilas, colas y deques según el orden requerido.
- [ ] Distingo Set de Map y justifico una implementación.
- [ ] Explico qué es una colisión y cómo puede resolverse.
- [ ] Identifico raíz, hijos, hojas y altura en un árbol.
- [ ] Explico la propiedad de un árbol binario de búsqueda.
- [ ] Comprendo para qué sirve una cola de prioridad.
- [ ] Represento un grafo con matriz y lista de adyacencia.
- [ ] Comprendo la finalidad de un índice auxiliar.
- [ ] Combino varias estructuras sin asignarles responsabilidades redundantes.

## Criterio

- [ ] Puedo justificar una estructura por las operaciones que necesito.
- [ ] Considero tamaño, orden, duplicados, búsqueda, inserción y eliminación.
- [ ] No elijo una estructura solo porque conozco su sintaxis.
- [ ] Pruebo casos vacíos, duplicados, límites y claves inexistentes.
