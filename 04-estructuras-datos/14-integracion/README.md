# 14 · Integración

**Nivel:** Intermedio

**Objetivo:** Construir un pequeño sistema en memoria que combine varias estructuras y justificar por qué cada una existe.

## Qué debes comprender

- modelo integrado
- índice por clave
- unicidad
- prioridad
- trazabilidad de operaciones
- justificación de estructuras

## Cómo trabajar el tema

1. Revisa `java/ejemplos` o `scala/ejemplos` para observar el uso mínimo.
2. Cuando exista `implementaciones/`, léela para entender cómo se construye la estructura.
3. Revisa las prácticas completas.
4. Resuelve el reto sin abrir `soluciones/`.
5. Compara tu decisión y prueba casos límite.

## Reto

Construye un gestor de recursos que combine una lista principal, un índice por código, categorías únicas y solicitudes por prioridad.

## Para avanzar

Debes poder explicar **por qué esta estructura es adecuada**, no solo escribir su sintaxis.

## Laboratorio integrador

Después del reto completa [`laboratorio-catalogo-aprendizaje.md`](./laboratorio-catalogo-aprendizaje.md). El laboratorio no incluye una solución para que la selección de estructuras sea una decisión propia y justificable.
