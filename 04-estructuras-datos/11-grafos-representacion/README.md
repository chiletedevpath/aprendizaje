# 11 · Grafos: representación

**Nivel:** Intermedio

**Objetivo:** Modelar vértices y aristas mediante listas o matrices de adyacencia sin adelantar algoritmos de recorrido o camino mínimo.

## Qué debes comprender

- vértice
- arista
- peso
- matriz de adyacencia
- lista de adyacencia
- grafo dirigido/no dirigido

## Cómo trabajar el tema

1. Revisa `java/ejemplos` o `scala/ejemplos` para observar el uso mínimo.
2. Cuando exista `implementaciones/`, léela para entender cómo se construye la estructura.
3. Revisa las prácticas completas.
4. Resuelve el reto sin abrir `soluciones/`.
5. Compara tu decisión y prueba casos límite.

## Reto

Representa una red de sedes con lista de adyacencia y muestra los vecinos directos de una sede. No implementes BFS/DFS todavía.

## Para avanzar

Debes poder explicar **por qué esta estructura es adecuada**, no solo escribir su sintaxis.
