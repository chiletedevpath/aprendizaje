# 05 · Patrones de comportamiento

Coordinan responsabilidades, comunicación y variaciones de comportamiento.

| Patrón | Idea central |
|---|---|
| Chain of Responsibility | pasar una solicitud por una cadena de manejadores. |
| Command | encapsular una acción como objeto. |
| Interpreter | representar y evaluar una gramática pequeña. |
| Iterator | recorrer una colección sin exponer su estructura interna. |
| Mediator | centralizar coordinación entre varios participantes. |
| Memento | capturar y restaurar estado sin romper encapsulamiento. |
| Observer | notificar cambios a múltiples interesados. |
| State | cambiar comportamiento según el estado interno. |
| Strategy | intercambiar una estrategia de cálculo o decisión. |
| Template Method | fijar el esqueleto de un proceso y permitir variaciones en pasos. |
| Visitor | agregar operaciones sobre una estructura estable de tipos. |

## Reto

Modela un proceso de aprobación de solicitudes con validaciones encadenadas y diferentes estrategias de prioridad. Justifica Chain of Responsibility y Strategy por separado.
