# 01 · Fundamentos de diseño

Antes de elegir un patrón, aprende a reconocer el problema.

## Conceptos

- responsabilidad y motivo de cambio;
- cohesión y acoplamiento;
- abstracción y dependencia;
- composición frente a herencia;
- code smells: clase grande, método largo, duplicación, condicionales crecientes y dependencias concretas.

## Reto

Refactoriza un servicio que calcula un pedido, lo guarda y además envía una notificación. Mantén el comportamiento, pero separa responsabilidades sin crear clases que no aporten una función clara.
