# Checklist de avance

## Diseño

- [ ] Distingo cohesión de acoplamiento.
- [ ] Puedo separar responsabilidades sin crear clases arbitrarias.
- [ ] Prefiero composición sobre herencia cuando no existe una relación de sustitución clara.
- [ ] Identifico dependencias concretas que dificultan pruebas o cambios.

## SOLID

- [ ] Explico SRP, OCP, LSP, ISP y DIP con ejemplos propios.
- [ ] Puedo detectar una violación sin depender del nombre del principio.
- [ ] Sé que SOLID orienta decisiones y no exige una cantidad determinada de interfaces o clases.

## GoF

- [ ] Distingo Factory Method de Abstract Factory.
- [ ] Distingo Adapter, Facade, Decorator y Proxy.
- [ ] Distingo Strategy de State.
- [ ] Comprendo cuándo Observer introduce desacoplamiento y cuándo puede dificultar el flujo.
- [ ] Puedo justificar al menos un patrón de cada familia.

## Criterio

- [ ] Comparo un patrón con una solución más simple antes de aplicarlo.
- [ ] Reconozco sobreingeniería y antipatrones comunes.
- [ ] Puedo refactorizar manteniendo el comportamiento esperado.
- [ ] En un caso integrador justifico cada patrón por un problema concreto.
