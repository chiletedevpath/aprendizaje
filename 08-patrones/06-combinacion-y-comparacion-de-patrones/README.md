# 06 · Combinación y comparación de patrones

Conocer patrones aislados no basta. Esta etapa compara intenciones y muestra combinaciones útiles.

## Comparaciones clave

- Strategy vs State.
- Adapter vs Facade vs Proxy.
- Decorator vs Proxy.
- Factory Method vs Abstract Factory.
- Observer vs Mediator.

## Combinaciones

- Strategy + Factory Method.
- Observer + State.
- Command + Memento.
- Adapter + Facade.

## Reto

Una aplicación debe integrar mensajería externa, avisar cambios de estado y permitir distintos criterios de prioridad. Diseña una solución mínima y argumenta qué combinación usarías y qué patrón descartarías.
