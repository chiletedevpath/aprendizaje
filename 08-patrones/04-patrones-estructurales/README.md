# 04 · Patrones estructurales

Organizan cómo se conectan objetos y clases.

| Patrón | Intención |
|---|---|
| Adapter | traducir una interfaz a otra esperada. |
| Bridge | separar una abstracción de su implementación. |
| Composite | tratar objetos individuales y composiciones con el mismo contrato. |
| Decorator | agregar comportamiento envolviendo un objeto. |
| Facade | ofrecer una entrada simple a un subsistema. |
| Flyweight | compartir estado repetido entre muchos objetos similares. |
| Proxy | intermediar y controlar el acceso a otro objeto. |

## Reto

Diseña una salida de reportes donde puedan agregarse auditoría y compresión sin modificar la implementación base. Compara Decorator con Proxy antes de elegir.
