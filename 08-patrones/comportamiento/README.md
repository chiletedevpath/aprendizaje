# Patrones de comportamiento

Ejercicios sobre patrones que organizan comunicacion, cambios de estado, acciones y recuperacion de informacion entre objetos.

## Contenido

- `java/state/reproductor`: cambio de comportamiento segun el estado de un reproductor.
- `java/observer/canal-video`: notificacion a suscriptores cuando un canal publica contenido.
- `java/command/control-remoto`: acciones encapsuladas como comandos para controlar una luz.
- `java/memento/editor-texto`: guardado y recuperacion del estado de un editor.

## Proposito

Comprender como los objetos colaboran sin depender de decisiones rigidas dentro de una sola clase.

## Uso comunitario

Cada ejercicio puede convertirse en guia si se explica el problema, el patron aplicado, el flujo de clases y el beneficio concreto frente a una solucion mas acoplada.
