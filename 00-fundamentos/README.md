# 00 · Fundamentos

Este módulo inicia la ruta de aprendizaje de **Chilete DevPath**. Su propósito es desarrollar el razonamiento necesario para analizar un problema antes de expresarlo en pseudocódigo o convertirlo en un programa.

No necesitas experiencia previa ni un lenguaje de programación para comenzar.

## Objetivo de la etapa

Al finalizar este módulo deberías poder:

- delimitar un problema y reconocer su resultado esperado;
- diferenciar requisitos, reglas, restricciones y supuestos;
- descomponer una situación en partes manejables;
- identificar entrada, validaciones, proceso y salida;
- diseñar casos normales, límite e inválidos;
- detectar errores de comprensión, datos, lógica y secuencia;
- explicar una solución y dejar evidencia verificable del proceso.

## Ruta recomendada

1. Lee [base-conceptual.md](base-conceptual.md).
2. Consulta [glosario.md](glosario.md) cuando un término no esté claro.

8. Revisa [checklist-avance.md](checklist-avance.md).

## Criterio de avance

La etapa se considera lograda cuando puedes recibir un problema sencillo y, antes de programar:

1. formular preguntas para comprenderlo;
2. definir objetivo y alcance;
3. declarar reglas, restricciones y supuestos;
4. ordenar una solución por pasos;
5. proponer casos que podrían hacerla fallar;
6. revisar y explicar las correcciones realizadas.

No necesitas memorizar todas las definiciones. Necesitas **aplicarlas con criterio**.

## Buenas prácticas de aprendizaje

El contenido técnico es el núcleo de esta etapa. Como práctica transversal de Chilete DevPath, también se recomienda:

- registrar cambios con nombres y commits comprensibles;
- reconocer autoría y fuentes externas;
- declarar el uso de IA cuando influya en material publicado;
- conservar evidencia suficiente para explicar lo realizado;
- priorizar comprensión y revisión sobre velocidad.
