# Fundamentos

Este módulo inicia la ruta de aprendizaje de Chilete DevPath. Está pensado para comprender cómo se analiza un problema antes de expresarlo en pseudocódigo o convertirlo en un programa.

Aquí se trabajan pensamiento computacional, entrada-proceso-salida, requisitos, reglas, restricciones, validación, casos de prueba y organización básica del aprendizaje.

## Objetivo

Desarrollar una forma clara de analizar problemas, proponer pasos y comprobar resultados antes de comenzar con sintaxis, variables y estructuras de control.

## Público objetivo

Este módulo está dirigido a:

- estudiantes que empiezan desde cero;
- personas que han intentado programar, pero necesitan fortalecer su razonamiento;
- miembros de la comunidad que buscan una base antes de usar PSeInt o un lenguaje;
- estudiantes que quieren explicar y comprobar sus soluciones.

## Temas principales

- Dato, información, problema, objetivo y resultado esperado.
- Requisitos, reglas, restricciones y supuestos.
- Descomposición, reconocimiento de patrones y abstracción.
- Entrada, proceso y salida.
- Validación y diseño de casos de prueba.
- Errores de comprensión, datos, lógica y secuencia.
- Organización de prácticas y control básico de cambios.
- Estudio responsable, autoría, fuentes y uso de IA.

## Estructura del módulo

- `base-conceptual.md`: contenido central que debe comprenderse antes de practicar.
- `guia-de-estudio.md`: método para estudiar, resolver y revisar una práctica.
- `glosario.md`: términos básicos para entender el módulo.
- `plantilla-evidencia.md`: registro breve para documentar una práctica.
- `checklist-avance.md`: autoevaluación para saber si ya puedes avanzar a pseudocódigo.
- `ejercicios-propuestos/`: retos para practicar antes de mirar una solución.
- `ejercicios-resueltos/`: soluciones explicadas paso a paso.
- `laboratorios/`: prácticas integradoras que producen una evidencia.

## Cómo usar este módulo

1. Lee `base-conceptual.md` y construye ejemplos propios.
2. Consulta el glosario cuando un término no esté claro.
3. Usa la guía de estudio para preparar una sesión.
4. Resuelve los ejercicios propuestos sin revisar primero las soluciones.
5. Compara el razonamiento, no solo la respuesta final.
6. Completa al menos un laboratorio y registra su evidencia.
7. Revisa el checklist de avance.
8. Continúa con `01-pseudocodigo` cuando puedas explicar y probar una solución.

## Criterio de avance

Este módulo se considera logrado cuando puedes:

- delimitar un problema y su resultado esperado;
- distinguir requisito, regla, restricción y supuesto;
- descomponer una situación en partes manejables;
- separar entrada, proceso y salida;
- proponer casos normales, límite e inválidos;
- explicar por qué una secuencia de pasos debería funcionar;
- registrar una evidencia breve y verificable;
- reconocer cuándo una fuente o el apoyo de IA debe declararse.
