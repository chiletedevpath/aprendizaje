# Ejercicio 01 · Del dato a la información

## Objetivo

Diferenciar un dato aislado de información interpretada dentro de un contexto.

## Situación

Una lista contiene estos valores:

```txt
12, 18, 15, 10, 20
```

## Responde

1. ¿Por qué estos valores, sin contexto, son solo datos?
2. Agrega un contexto que permita interpretarlos.
3. Obtén una información útil a partir de ellos.
4. Indica una decisión que podría tomarse con esa información.

## Evidencia esperada

Una explicación breve donde se reconozca claramente la relación:

```txt
datos -> contexto -> información -> decisión
```

Cuando termines tu primer intento, contrasta tu razonamiento con la [solución de referencia](../ejercicios-resueltos/01-datos-e-informacion.md).
