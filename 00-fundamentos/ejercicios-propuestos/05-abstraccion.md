# Ejercicio 05 · Elegir lo relevante

## Objetivo

Aplicar abstracción para separar información relevante, posiblemente relevante e irrelevante.

## Situación

Para calcular el precio de entrega de un paquete se conocen:

- peso;
- destino;
- tipo de entrega;
- color de la caja;
- nombre de quien preparó el paquete;
- dimensiones;
- nivel de urgencia.

## Actividad

Clasifica los datos en:

- necesarios;
- posiblemente necesarios;
- irrelevantes para este cálculo.

Explica qué información adicional necesitarías antes de tomar una decisión definitiva.

## Evidencia esperada

Una clasificación razonada, incluyendo cualquier dato que no pueda clasificarse con seguridad sin conocer las reglas del servicio.

Luego revisa la [solución de referencia](../ejercicios-resueltos/05-abstraccion.md).
