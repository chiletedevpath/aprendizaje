# Ejercicio 03 · Requisitos y límites

## Objetivo

Diferenciar requisito, regla, restricción y supuesto.

## Situación

Una biblioteca desea registrar préstamos de libros.

Clasifica cada afirmación:

1. El sistema debe registrar la fecha del préstamo.
2. Solo se presta un libro si existe una copia disponible.
3. La primera versión no enviará notificaciones.
4. Se considera que cada libro ya tiene un código único.

## Actividad

Para cada afirmación indica si corresponde a:

- requisito;
- regla;
- restricción;
- supuesto.

Explica brevemente por qué.

## Evidencia esperada

Una clasificación justificada. No basta con colocar una etiqueta.

Después de responder, contrasta con la [solución de referencia](../ejercicios-resueltos/03-requisitos-y-limites.md).
