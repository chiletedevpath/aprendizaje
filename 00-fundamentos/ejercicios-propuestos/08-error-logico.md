# Ejercicio 08 · Encontrar el error lógico

## Objetivo

Detectar un error lógico y proponer una secuencia corregida que pueda comprobarse.

## Secuencia propuesta

Para calcular el promedio de tres notas alguien plantea:

1. Dividir la primera nota entre tres.
2. Sumar las otras dos notas.
3. Mostrar el resultado.

## Responde

- ¿Qué tipo de error existe?
- ¿Por qué la secuencia no representa el cálculo correcto?
- ¿Cómo debería ordenarse?
- ¿Con qué caso de prueba demostrarías la corrección?

## Evidencia esperada

Una explicación del error, una secuencia corregida y al menos un caso de prueba.

Consulta después la [solución de referencia](../ejercicios-resueltos/08-error-logico.md).
