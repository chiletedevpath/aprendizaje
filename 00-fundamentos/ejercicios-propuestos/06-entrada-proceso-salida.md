# Ejercicio 06 · Entrada, proceso y salida

## Objetivo

Representar una solución sin utilizar todavía código ni pseudocódigo.

## Situación

Un sistema determina si una persona aprueba un curso usando tres notas y una nota mínima aprobatoria.

## Identifica

- entradas;
- validaciones;
- proceso;
- salida;
- reglas;
- al menos un supuesto que debería confirmarse.

## Restricción

No escribas código ni pseudocódigo.

## Evidencia esperada

Una tabla o lista donde se diferencie claramente cada elemento de la solución.

Después compara con la [solución de referencia](../ejercicios-resueltos/06-entrada-proceso-salida.md).
