# Excel y productividad

Ruta complementaria de Chilete DevPath para aprender a organizar datos, construir cálculos, comprobar resultados y comunicar información mediante hojas de cálculo.

Puede estudiarse en paralelo a la ruta de desarrollo de software. Los módulos iniciales contienen una práctica resuelta y un reto. Los módulos integradores reúnen varias hojas relacionadas y cierran con un reto que aplica el sistema completo.

## De proyectos grandes a contenidos de aprendizaje

Los proyectos aplicados sirven como fuente para detectar competencias, pero no se publican como plantillas completas dentro de esta ruta. Cada sistema se descompone en prácticas progresivas con datos ficticios, fórmulas explicables y retos verificables.

| Proyecto fuente | Contenidos que aporta | Aplicación en la ruta |
|---|---|---|
| Control de obra para constructora | Registro estructurado, costos por jornada, presupuestos, estados, consolidación y resumen operativo | Los módulos 00 al 07 preparan las habilidades fundamentales y el módulo 08 las integra en un caso operativo. |
| Sistema de finanzas personales | Movimientos, clasificación, agregaciones con criterios, presupuesto frente a gasto, metas, deudas y resumen financiero | Los módulos 02, 04, 05 y 06 introducen los cálculos necesarios; el módulo 09 los combina en un modelo financiero personal. |

Esta descomposición evita saltar directamente a archivos complejos. El estudiante aprende primero cada recurso, luego relaciona varias hojas y finalmente comprende cómo se construye un sistema completo.

## Forma de trabajo

1. En los módulos 00 al 07, abre la hoja `Practica resuelta` y sigue las fórmulas desde los datos hasta el resultado.
2. En los módulos 08 y 09, comienza por `Resumen` y rastrea cada resultado hasta las hojas que contienen sus datos y cálculos.
3. Cambia valores ficticios y comprueba qué resultados se actualizan.
4. Resuelve la hoja `Reto`; las celdas amarillas señalan entradas o trabajo pendiente según las instrucciones del libro.
5. Comprueba formatos, fórmulas, referencias y resultados antes de avanzar.
6. Conserva una copia sin resolver si deseas repetir la práctica.

## Criterio de avance

Avanza cuando puedas explicar el propósito de cada fórmula, distinguir una entrada de un cálculo, corregir un error de referencia y presentar una tabla legible sin depender de una plantilla preconstruida.

Los libros de esta ruta fueron reconstruidos con nombres, casos, datos y diseño originales de Chilete DevPath. No incluyen información personal real, archivos de clientes ni plantillas de terceros.
