# 04 · Ordenamientos elementales

**Nivel:** Básico

**Objetivo:** Comprender Bubble, Selection e Insertion Sort y comparar su comportamiento sobre entradas pequeñas.

## Conceptos clave

- Bubble Sort
- Selection Sort
- Insertion Sort
- intercambios y desplazamientos
- O(n²)

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Implementa Bubble, Selection e Insertion Sort sobre el mismo arreglo y registra cuántas comparaciones e intercambios/desplazamientos realiza cada uno.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
