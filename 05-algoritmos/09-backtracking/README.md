# 09 · Backtracking

**Nivel:** Intermedio

**Objetivo:** Explorar decisiones, detectar caminos inválidos y retroceder de forma sistemática.

## Conceptos clave

- espacio de decisiones
- restricción
- marcar/desmarcar
- retroceso
- poda básica

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Resuelve un Sudoku 4x4 mediante backtracking. Debes validar fila, columna y subcuadrícula antes de aceptar una decisión.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
