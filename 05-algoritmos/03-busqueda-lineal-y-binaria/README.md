# 03 · Búsqueda lineal y binaria

**Nivel:** Básico

**Objetivo:** Comparar búsquedas lineales y binarias, reconocer sus precondiciones y costos.

## Conceptos clave

- búsqueda lineal
- búsqueda binaria
- datos ordenados
- O(n) frente a O(log n)
- búsqueda por bloques

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Busca un código dentro de 1000 valores ordenados usando búsqueda lineal y binaria. Cuenta comparaciones y contrasta los resultados.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
