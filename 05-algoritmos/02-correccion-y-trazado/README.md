# 02 · Corrección y trazado

**Nivel:** Básico

**Objetivo:** Seguir paso a paso un algoritmo, definir precondiciones y verificar que mantenga resultados coherentes.

## Conceptos clave

- traza manual
- precondición
- postcondición
- invariante
- casos de prueba

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Traza manualmente un algoritmo que calcule el máximo de un arreglo y registra el valor de `maximo` después de cada iteración. Luego implementa una verificación automática.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
