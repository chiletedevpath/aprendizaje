# 05 · Algoritmos

Esta etapa estudia **cómo diseñar, analizar y comparar estrategias para resolver problemas**.

En `04-estructuras-datos` aprendiste cómo organizar la información. Aquí el foco cambia: ahora debes decidir **qué pasos ejecutar, en qué orden, bajo qué precondiciones y con qué costo aproximado**.

## Antes de empezar

Conviene dominar:

- programación básica y métodos;
- recursión elemental;
- arreglos y colecciones;
- listas, pilas, colas, árboles y grafos;
- notación Big O a nivel introductorio.

## Cómo está organizada la práctica

Cada tema contiene:

```text
README.md
├── java/
│   ├── ejemplos/     → algoritmo pequeño y explicado
│   ├── practicas/    → ejercicios completos desarrollados
│   └── soluciones/   → solución del reto del tema
└── scala/
    ├── ejemplos/
    ├── practicas/
    └── soluciones/
```

Los comentarios del código son breves y técnicos. Explican decisiones, precondiciones o comportamientos relevantes; no describen líneas evidentes.

## Qué debes poder hacer al terminar

- reconocer cuándo una búsqueda binaria es válida y cuándo no;
- comparar algoritmos de ordenamiento más allá de “funciona/no funciona”;
- construir una solución recursiva con caso base correcto;
- distinguir divide y vencerás, greedy, backtracking y programación dinámica;
- recorrer grafos y calcular caminos o conectividad;
- elegir un algoritmo considerando precondiciones, tiempo y memoria;
- justificar por qué una estrategia es adecuada para un problema concreto.
