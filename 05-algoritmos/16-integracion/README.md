# 16 · Integración

**Nivel:** Intermedio

**Objetivo:** Combinar estructuras y algoritmos en una solución completa, justificando las decisiones adoptadas.

## Conceptos clave

- integración
- justificación
- medición empírica
- casos de prueba
- documentación de decisiones

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Construye un planificador de rutas que represente una red, encuentre una ruta mínima y permita consultar conectividad. Documenta estructuras, algoritmos y precondiciones.

Después desarrolla el [laboratorio integrador: planificador de una ruta de aprendizaje](laboratorio-planificador-ruta-aprendizaje.md), que reúne búsquedas, ordenamiento y algoritmos de grafos en un escenario completo.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
