# 08 · Algoritmos voraces

**Nivel:** Intermedio

**Objetivo:** Tomar decisiones locales justificadas y reconocer cuándo una estrategia greedy es válida.

## Conceptos clave

- decisión local
- criterio greedy
- factibilidad
- ordenamiento previo cuando corresponde
- limitaciones del enfoque

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Selecciona la mayor cantidad de actividades compatibles a partir de intervalos inicio/fin. Ordena por hora de finalización y justifica el criterio.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
