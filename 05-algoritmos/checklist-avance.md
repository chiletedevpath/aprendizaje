# Checklist de avance

## Análisis

- [ ] Identifico entrada, salida y precondiciones de un algoritmo.
- [ ] Realizo una traza manual sobre un caso pequeño.
- [ ] Interpreto O(1), O(log n), O(n), O(n log n) y O(n²).
- [ ] Distingo costo temporal de costo espacial.

## Estrategias

- [ ] Comparo búsqueda lineal y binaria.
- [ ] Explico diferencias entre ordenamientos elementales y eficientes.
- [ ] Construyo una recursión con caso base y progreso hacia ese caso.
- [ ] Distingo divide y vencerás, greedy, backtracking y programación dinámica.
- [ ] Aplico memoización y tabulación en un problema con subproblemas repetidos.

## Grafos y secuencias

- [ ] Implemento BFS y DFS.
- [ ] Comprendo la relajación utilizada por Dijkstra.
- [ ] Distingo alcanzabilidad de camino mínimo.
- [ ] Comprendo el propósito de Prim y Kruskal.
- [ ] Reconozco cuándo usar dos punteros o ventana deslizante.

## Criterio

- [ ] No aplico búsqueda binaria sobre datos desordenados sin justificar un ordenamiento previo.
- [ ] Puedo explicar por qué un algoritmo funciona, no solo ejecutarlo.
- [ ] Comparo alternativas considerando tiempo, memoria y restricciones.
- [ ] Pruebo casos normales, límites, vacíos y entradas inválidas cuando corresponde.
