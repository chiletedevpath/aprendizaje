# 05 · Ordenamientos eficientes

**Nivel:** Básico avanzado

**Objetivo:** Estudiar Merge Sort, Quick Sort, Shell Sort y estrategias de mezcla para entradas mayores.

## Conceptos clave

- Merge Sort
- Quick Sort
- Shell Sort
- mezcla
- O(n log n) esperado

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Implementa Quick Sort y compáralo con Merge Sort sobre datos aleatorios y datos ya ordenados. No concluyas solo por una ejecución.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
