# 14 · Técnicas sobre arreglos y cadenas

**Nivel:** Intermedio

**Objetivo:** Aplicar dos punteros, ventana deslizante y conteo eficiente sobre secuencias.

## Conceptos clave

- dos punteros
- ventana deslizante
- frecuencias
- prefijos básicos
- secuencias contiguas

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Encuentra la longitud máxima de una subcadena sin caracteres repetidos usando ventana deslizante.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
