# 15 · Selección y comparación algorítmica

**Nivel:** Intermedio

**Objetivo:** Elegir una estrategia según precondiciones, complejidad, memoria y características de los datos.

## Conceptos clave

- precondiciones
- complejidad
- memoria
- tamaño de entrada
- claridad y mantenibilidad

## Orden recomendado

1. Revisa `java/ejemplos/` o `scala/ejemplos/`.
2. Estudia las prácticas completas disponibles.
3. Resuelve el reto sin consultar `soluciones/`.
4. Compara tu razonamiento y prueba casos adicionales.

## Reto

Para tres problemas propuestos, elige entre búsqueda lineal/binaria, greedy, backtracking o programación dinámica y justifica la elección antes de programar.

## Criterio para avanzar

Debes poder explicar **qué precondiciones necesita la estrategia, por qué produce el resultado esperado y cuál es su costo aproximado**.
