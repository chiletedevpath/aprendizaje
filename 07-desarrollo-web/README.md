# 07 · Desarrollo web

Esta etapa enseña a construir interfaces web con **HTML semántico, CSS responsive y JavaScript del navegador** antes de utilizar frameworks frontend.

## Antes de empezar

Conviene dominar programación básica, funciones, colecciones y manejo elemental de errores. PHP, APIs y persistencia del lado servidor pertenecen a `09-backend`.

## Ruta

1. Comprende cliente, servidor, URL, DNS y HTTP.
2. Construye documentos HTML semánticos, formularios y multimedia accesible.
3. Aprende cascada, box model, posicionamiento, Flexbox, Grid y responsive mobile first.
4. Usa JavaScript para interactuar con DOM, eventos, formularios, Fetch, JSON y Storage.
5. Aplica Bootstrap como framework CSS sin ocultar los fundamentos.
6. Revisa accesibilidad, rendimiento y comportamiento en navegador.
7. Cierra con una práctica integradora, no con un proyecto académico.

Consulta [ruta-de-aprendizaje.md](ruta-de-aprendizaje.md) para ver las 14 etapas.

## Organización didáctica

- `ejemplos/`: demostraciones pequeñas de un concepto.
- `practicas/`: ejercicios desarrollados que combinan conceptos.
- `Reto` en cada tema: actividad para resolver antes de avanzar.
- `14-integracion-web`: laboratorio final de la etapa.

## Criterio de logro

Al finalizar debes poder construir y explicar un sitio que:

- use HTML semántico;
- responda desde 320 px hasta escritorio;
- funcione con teclado y mantenga foco visible;
- integre DOM, formularios, Fetch/JSON y almacenamiento local;
- controle estados normales y de error;
- cargue sin referencias locales rotas ni errores de JavaScript.
