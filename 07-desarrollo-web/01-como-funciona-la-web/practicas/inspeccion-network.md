# Práctica · Inspección de red

1. Abre una página de práctica en el navegador.
2. Abre DevTools → Network y recarga.
3. Identifica el documento HTML y al menos un recurso CSS, JavaScript o imagen.
4. Registra método, estado HTTP y tipo de recurso.
5. Explica qué recurso bloquea o modifica la presentación si deja de cargar.
