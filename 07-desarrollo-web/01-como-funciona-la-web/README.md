# Cómo funciona la web

## Qué debes dominar

- cliente y servidor
- URL y recursos
- DNS a nivel conceptual
- HTTP/HTTPS
- petición y respuesta
- HTML, CSS y JavaScript como recursos del navegador

## Reto

Abre DevTools > Network en un sitio de prueba e identifica documento HTML, CSS, JavaScript e imágenes.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
