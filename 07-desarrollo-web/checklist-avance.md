# Checklist de avance

Antes de avanzar a frontend o backend, deberías poder:

- [ ] Explicar, a nivel básico, URL → DNS → HTTP/HTTPS → servidor → navegador.
- [ ] Crear HTML semántico sin depender de `div` para toda la estructura.
- [ ] Construir formularios con `label`, tipos de entrada y validaciones HTML.
- [ ] Explicar cascada, especificidad, box model y posicionamiento.
- [ ] Maquetar con Flexbox y Grid y adaptar una interfaz con enfoque mobile first.
- [ ] Conectar JavaScript mediante `defer` y diferenciar lenguaje JavaScript de APIs del navegador.
- [ ] Consultar y modificar el DOM y gestionar eventos con `addEventListener`.
- [ ] Consumir JSON mediante `fetch`, `async/await` y manejo de errores.
- [ ] Usar `localStorage` sin almacenar secretos.
- [ ] Utilizar Bootstrap entendiendo qué resuelve cada clase/componente.
- [ ] Revisar navegación por teclado, textos alternativos, foco y contraste básico.
- [ ] Usar DevTools para depurar estilos, scripts y peticiones de red.
- [ ] Construir una práctica integradora sin framework frontend.
