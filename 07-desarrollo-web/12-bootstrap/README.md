# Bootstrap con criterio

## Qué debes dominar

- container
- grid de 12 columnas
- breakpoints
- utilities
- navbar
- cards
- modal/collapse
- formularios
- CSS propio cuando sea necesario

## Reto

Construye un panel responsive con tarjetas y un componente interactivo sin ocultar la estructura semántica del HTML.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
