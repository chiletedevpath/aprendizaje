# Bootstrap con criterio

## Qué debes dominar

- container
- grid de 12 columnas
- breakpoints
- utilities
- navbar
- cards
- modal/collapse
- formularios
- CSS propio cuando sea necesario

## Reto

Construye un panel responsive con tarjetas y un componente interactivo sin ocultar la estructura semántica del HTML.

## Práctica guiada

- [Exploradores del Código](practicas/exploradores-codigo/): catálogo temático original para practicar grid, navbar, cards, modal, formulario y personalización responsable de Bootstrap.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
