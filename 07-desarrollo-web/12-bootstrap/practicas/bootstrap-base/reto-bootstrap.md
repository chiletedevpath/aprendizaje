# Reto: panel responsive con Bootstrap

Construye un panel de cursos después de revisar `index.html`. No copies la práctica resuelta.

## Requisitos

1. Usa un `container` y una rejilla de doce columnas.
2. Muestra una tarjeta por curso: HTML, CSS y JavaScript.
3. Presenta una columna en móvil, dos en tablet y tres en escritorio.
4. Agrega una insignia que indique el nivel de cada curso.
5. Incluye un componente `collapse` con los requisitos previos.
6. Conserva encabezados jerárquicos, controles con nombre accesible y foco visible.
7. Añade CSS propio solamente si una necesidad no puede resolverse claramente con Bootstrap.

## Comprobación

- La página no debe tener desplazamiento horizontal a 320 píxeles.
- Los controles deben funcionar mediante teclado.
- El HTML debe seguir siendo comprensible si Bootstrap no carga.
- Debes poder explicar qué resuelve cada clase utilizada.
