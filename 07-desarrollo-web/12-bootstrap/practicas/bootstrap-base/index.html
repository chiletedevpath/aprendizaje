Fundamentos de Bootstrap

Práctica resuelta para reconocer contenedores, rejilla, utilidades y componentes.

Antes de empezar

Bootstrap no reemplaza el aprendizaje de CSS. Conviene utilizarlo después de comprender el modelo de caja, Flexbox, Grid y diseño responsive.

1. Contenedor y rejilla responsive

La clase container limita el ancho del contenido. La combinación row y col-* organiza una rejilla de doce columnas.

HTML semántico

La estructura sigue perteneciendo al documento HTML.

Clases de Bootstrap

Las clases aplican reglas CSS ya preparadas.

CSS propio

Se añade solamente cuando el diseño necesita personalización.

2. Utilidades

Clases como p-3, mb-3, text-center y d-flex resuelven ajustes frecuentes sin crear una regla nueva para cada caso.

3. Componente interactivo

Algunos componentes necesitan el JavaScript de Bootstrap. El botón siguiente controla un bloque colapsable mediante atributos data-bs-*.

Bootstrap administra la interacción; el contenido continúa siendo HTML accesible.
