# Exploradores del Código

Práctica académica no comercial para aplicar grid, tarjetas, navegación responsive, formularios, validación y modales de Bootstrap.

Todo el contenido narrativo y visual de esta versión es original de Chilete DevPath. Los fondos e ilustraciones se generan con CSS; no utiliza imágenes, personajes ni marcas de terceros.

## Ejecución

Abre `index.html` mediante un servidor local. La práctica carga Bootstrap 5.3.8 desde jsDelivr, por lo que necesita conexión a Internet para obtener esa dependencia.

El formulario es demostrativo: valida los campos en el navegador, pero no transmite ni almacena información.

## Comprobaciones

1. Prueba el menú en una pantalla de 320 px.
2. Abre el modal desde cada tarjeta.
3. Envía el formulario vacío y luego con datos ficticios.
4. Activa la preferencia de movimiento reducido y verifica que no dependa de animaciones.
