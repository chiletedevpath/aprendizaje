# Laboratorio Bootstrap y transformaciones CSS

Práctica educativa para combinar Bootstrap 5 con CSS propio y una interacción breve en JavaScript. Presenta ejemplos conceptuales y no envía información a un servidor.

## Conceptos aplicados

- navbar adaptable y componente `collapse`;
- `container`, `row`, columnas y breakpoints;
- tarjetas y formularios de Bootstrap;
- transformaciones `rotate`, `scale`, `translate` y una tarjeta 3D;
- transiciones, `@keyframes` y alternativa para movimiento reducido;
- eventos `submit` y `reset` con respuesta accesible mediante `aria-live`.

Abre `index.html` directamente o mediante Live Server. Bootstrap se carga desde jsDelivr con verificación de integridad; por ello se necesita conexión para aplicar el framework.

## Qué observar

Compara qué responsabilidades resuelve Bootstrap y cuáles permanecen en `css/estilos.css`. El formulario es deliberadamente demostrativo: valida la entrada, pero no transmite datos.

Contenido adaptado para Chilete DevPath con apoyo de IA para estructuración y revisión. El criterio, selección y validación final corresponden a Adrian Pisco, autor de Chilete DevPath.
