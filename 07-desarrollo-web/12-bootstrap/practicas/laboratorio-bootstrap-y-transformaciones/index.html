Qué debes observar en esta práctica

Bootstrap resuelve la cuadrícula, los puntos de quiebre, la navegación y los controles del formulario. El CSS propio añade identidad, transformaciones 2D y 3D, transiciones y @keyframes. JavaScript solo gestiona el formulario demostrativo y el cierre del menú móvil.
