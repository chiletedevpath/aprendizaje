# Chilete DevPath Academy

Proyecto académico demostrativo para **Marcos de Desarrollo Web**.

## Escenario elegido

**Opción A – Academia de cursos**

La página permite:

- presentar cursos;
- consultar detalles mediante un Modal;
- enviar una consulta;
- solicitar información mediante un formulario dentro de un Modal;
- navegar desde celular, tablet o computadora.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8
- Bootstrap Icons

## Ejecutar

1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` o utiliza Live Server.
4. Mantén conexión a Internet para Bootstrap, Icons e imágenes externas.

Si una fotografía externa falla, JavaScript muestra automáticamente una imagen de respaldo.
