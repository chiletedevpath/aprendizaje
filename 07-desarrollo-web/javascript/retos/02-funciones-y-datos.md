# Retos: funciones y estructuras de datos

1. Implementa una función que reciba recursos y devuelva únicamente los publicados, sin alterar el arreglo original.
2. Cuenta etiquetas repetidas usando un `Map` y conserva la lista única mediante un `Set`.
3. Modela un recurso con propiedades, un objeto anidado para autoría y un método que produzca un resumen legible.
4. Combina dos catálogos con propagación, evitando compartir accidentalmente arreglos internos mutables.
5. Desestructura código, título y estado de un recurso; reúne el resto de propiedades en un nuevo objeto.
6. Implementa funciones para validar, agregar, buscar y retirar recursos. Prueba entradas vacías, códigos duplicados y códigos ausentes.

## Criterio

Cada función debe tener una responsabilidad, entrada y salida identificables. Evita imprimir dentro de funciones que deberían devolver un resultado reutilizable.
