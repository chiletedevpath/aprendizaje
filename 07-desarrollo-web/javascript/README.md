# JavaScript para la web

Este bloque conecta los fundamentos de programación con el navegador. Los retos no contienen soluciones y deben intentarse después de revisar `02-programacion-basica`.

## Ruta

1. `retos/01-lenguaje-y-control.md`: valores, operadores, texto, decisiones y bucles.
2. `retos/02-funciones-y-datos.md`: funciones, arreglos, conjuntos, mapas y objetos.
3. `retos/03-clases-modulos-y-errores.md`: clases, módulos y manejo de errores.
4. `asincronia/cafeteria-asincrona`: ejemplo resuelto de tareas asíncronas.
5. `laboratorio-integrador.md`: interacción completa con DOM, eventos y persistencia local.

## Ejecución

- Los retos de lenguaje pueden ejecutarse con Node.js o la consola del navegador.
- Los ejercicios con DOM deben abrirse mediante una página HTML.
- Los módulos necesitan `type="module"` y es recomendable servirlos desde un servidor local.

Los retos fueron redactados y contextualizados para Chilete DevPath.
