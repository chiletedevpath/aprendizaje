# Flexbox, Grid y responsive

## Qué debes dominar

- Flexbox
- Grid
- gap
- minmax y repeat
- media queries
- mobile first
- imágenes responsivas

## Reto

Maqueta una cuadrícula de tarjetas: una columna en móvil, dos en tablet y tres en escritorio.

## Prácticas

- `practicas/flexbox-layout`: distribución de elementos mediante Flexbox.
- `practicas/academia-flexbox`: composición más completa basada en Flexbox.
- `practicas/layout-grid-responsive`: layout semántico con áreas de Grid y cambios para móvil, tablet y escritorio.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
