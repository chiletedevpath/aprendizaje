# CSS moderno

## Qué debes dominar

- pseudo-clases
- pseudo-elementos
- custom properties
- calc/min/max/clamp
- transiciones
- transformaciones
- animación básica
- organización reutilizable
- preprocesadores CSS: variables, mixins, anidación y compilación con Less

## Reto

Crea un botón y una tarjeta reutilizables con estados de foco y hover, variables CSS y una transición breve.

## Prácticas

- `practicas/tarjeta-producto-less`: componente responsive que explica variables, mixins, anidación y compilación.
- `practicas/layout-empresarial-less`: layout mobile first que combina Less con áreas de CSS Grid.
- `practicas/efectos-css-en-accion`: transiciones, `@keyframes`, animación vinculada al scroll y alternativa con JavaScript.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
