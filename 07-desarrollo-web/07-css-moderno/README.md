# CSS moderno

## Qué debes dominar

- pseudo-clases
- pseudo-elementos
- custom properties
- calc/min/max/clamp
- transiciones
- transformaciones
- animación básica
- organización reutilizable

## Reto

Crea un botón y una tarjeta reutilizables con estados de foco y hover, variables CSS y una transición breve.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
