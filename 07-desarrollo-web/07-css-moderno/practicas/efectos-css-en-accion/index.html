01 / LECTURA

El movimiento como parte del diseño web

Una página no necesita animaciones complejas para sentirse interactiva. A veces, un pequeño movimiento ayuda al usuario a comprender qué está sucediendo.

Diseño e interacción Animaciones CSS

Las hojas de estilo en cascada permiten definir colores, tamaños, posiciones y distribuciones. Además, con las propiedades de animación de CSS, también podemos controlar cómo cambian los elementos de la interfaz .

Con @keyframes se establece el estado inicial y final de una animación. Después, la propiedad animation determina su duración, velocidad y repetición. El resultado puede ser tan simple como una transición suave o un elemento que gira sin detenerse.

1. La navegación responde a nuestras acciones

Un menú hamburguesa ocupa poco espacio y permite mostrar u ocultar opciones cuando el usuario lo necesita. En la cabecera, el icono de tres líneas permite desplegar las opciones de navegación sin ocupar espacio de forma permanente.

El diseño de las tres líneas se obtiene mediante un elemento y los pseudoelementos ::before y ::after . Al activar el menú, JavaScript agrega la clase active , mientras que CSS ejecuta la animación de entrada slideIn .

01
Navegación compacta

Al pulsar el icono de la cabecera, las opciones se despliegan suavemente. Al cerrar el menú, el contenido vuelve a quedar despejado.

2. Un botón también puede dar respuesta visual

Al hacer clic en un botón, el efecto de onda o ripple genera un círculo en el punto donde se ha pulsado. Este círculo aumenta de tamaño y desaparece gradualmente.

JavaScript obtiene la posición del clic y crea un elemento temporal. CSS se encarga de animarlo utilizando transform: scale() y opacity . Ambas tecnologías cumplen funciones diferentes y complementarias.

02 / INTERACTÚA

Pequeños movimientos, respuestas claras

Un botón puede confirmar una pulsación y un indicador giratorio puede comunicar movimiento sin distraer del contenido.

03 / DESPLÁZATE

Las imágenes aparecen al bajar

Las imágenes se revelan poco a poco conforme entran en pantalla. Su escala y transparencia cambian al ritmo del desplazamiento.

3. El desplazamiento puede controlar una animación

A diferencia del loader, que avanza con el tiempo, esta animación utiliza una línea de tiempo relacionada con la visibilidad de la imagen. Por eso, el efecto está asociado al desplazamiento de la página.

Las propiedades view-timeline-name , animation-timeline y animation-range establecen cuándo progresa la animación show .

04 / DETRÁS DEL MOVIMIENTO

Así funcionan estos efectos

CSS define el aspecto y las animaciones. JavaScript interviene cuando hay que detectar una acción o crear un elemento.
