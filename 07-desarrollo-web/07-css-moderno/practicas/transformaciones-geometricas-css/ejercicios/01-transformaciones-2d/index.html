Ejercicio 01 · 2D

Movimiento en dos dimensiones

Cuatro transformaciones sobre cuadrados. Coloca el cursor sobre cada figura o selecciónala con el teclado para observar el resultado.

Rotación

rotate(45deg)

Giro de 45 grados.

Traslación

translateX(50px)

Desplazamiento horizontal.

Escala

scale(1.5)

Aumento de tamaño.

Sesgado

skew(10deg, 10deg)

Inclinación en ambos ejes.

Las cuatro figuras utilizan transition: transform 0.5s para suavizar el movimiento.
