Ejercicio 03 · 2D + 3D

Hexágono Chilete DevPath

Una figura geométrica reversible. El desplazamiento y la escala se aplican en 2D; el giro entre las dos caras utiliza una transformación 3D.

Coloca el cursor sobre el hexágono o púlsalo para mostrar la otra cara.

Composición

Dos transformaciones, una figura

La figura conserva su forma hexagonal mientras cambia de posición y rota en profundidad. La imagen de Chilete DevPath permanece centrada en la cara frontal.

01

Movimiento 2D

translateY(-12px) scale(1.05) rotate(-6deg)

Eleva, amplía e inclina el hexágono.

02

Giro 3D

rotateY(180deg)

Gira la figura para mostrar su cara posterior.

03

Recorte geométrico

clip-path: polygon(...)

Define los seis lados del hexágono.

El giro también funciona con teclado: pulsa Tab hasta seleccionar la figura y luego Espacio para activarlo.
