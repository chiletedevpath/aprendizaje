Qué aporta Less en esta práctica

Variables
Centralizan colores, medidas y espaciados para evitar valores dispersos.
Mixins
Agrupan declaraciones reutilizables, como el estilo base del botón.
Anidación
Relaciona modificadores y elementos con su componente sin perder la jerarquía.
Compilación
El navegador recibe CSS; por eso estilos.less se compila en estilos.css.
