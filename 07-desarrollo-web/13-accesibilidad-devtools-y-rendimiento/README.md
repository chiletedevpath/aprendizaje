# Accesibilidad, DevTools y rendimiento

## Qué debes dominar

- HTML semántico
- teclado y foco
- label y alt
- ARIA solo cuando sea necesaria
- Elements/Console/Network/Application
- imágenes y lazy loading
- carga responsable de recursos

## Reto

Audita una práctica anterior solo con teclado y DevTools; registra tres mejoras concretas.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
