# HTML: estructura y semántica

## Qué debes dominar

- estructura mínima de un documento
- jerarquía de encabezados
- enlaces, listas e imágenes
- elementos semánticos
- rutas relativas y absolutas

## Reto

Construye una página de perfil académico usando `header`, `nav`, `main`, `section` y `footer` sin estilos.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
