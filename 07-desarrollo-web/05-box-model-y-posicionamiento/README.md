# Box model y posicionamiento

## Qué debes dominar

- content/padding/border/margin
- box-sizing
- display
- position
- z-index
- overflow

## Reto

Construye una tarjeta con medidas controladas y un elemento `sticky` sin usar Flexbox ni Grid.
