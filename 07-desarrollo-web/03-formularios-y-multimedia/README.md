# Formularios y multimedia

## Qué debes dominar

- form, label e input
- tipos de entrada
- validación HTML
- textarea/select/button
- img/picture/audio/video
- texto alternativo

## Reto

Crea un formulario de inscripción con validaciones HTML y una imagen con texto alternativo útil.

## Para avanzar

Debes poder explicar qué problema resuelve cada técnica utilizada y reproducirla sin copiar una plantilla completa.
