# Reto integrador · Sitio educativo

Construye un sitio web sin framework frontend que incluya:

- HTML semántico y navegación comprensible;
- layout responsive con Flexbox y/o Grid;
- formulario con validación;
- interacción DOM mediante eventos;
- lectura de un JSON mediante `fetch`;
- una preferencia no sensible en `localStorage`;
- navegación por teclado y foco visible;
- revisión final con Console y Network de DevTools.

## Restricciones

- No uses React, Vue, Angular, Astro ni backend.
- No guardes secretos en el navegador.
- Justifica cualquier dependencia externa.
