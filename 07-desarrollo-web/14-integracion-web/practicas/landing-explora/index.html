Aplicación responsive

¿Cómo adapté esta sección a diferentes dispositivos?

En esta parte de la web aplico diseño responsivo para que el contenido se adapte correctamente a celulares, tablets, laptops y pantallas grandes. El video cambia su tamaño automáticamente sin deformarse y la distribución se reorganiza según el espacio disponible.

  • Mobile first: parto de una estructura pensada para pantallas pequeñas y posteriormente la adapto para resoluciones mayores.
  • CSS Grid: lo utilizo para distribuir el contenido en columnas cuando existe suficiente espacio disponible.
  • Video responsive: mantengo su proporción y hago que se adapte automáticamente al ancho de su contenedor.
  • Media queries: las utilizo para modificar la distribución, tamaños y comportamiento de algunos elementos dependiendo del ancho de la pantalla.
