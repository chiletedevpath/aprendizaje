Validación de formularios y datos

Dos ejemplos para observar cómo JavaScript valida, transforma y presenta entradas sin recargar la página.

01

Validación de acceso

Comprueba el formato del correo y el dominio ficticio @aula.example.

Chilete DevPath explica: el evento submit se intercepta con preventDefault(). Después se normaliza el texto, se evalúan formato y dominio por separado y el resultado se construye con createElement y textContent, sin insertar HTML recibido del usuario.
02

Datos del estudiante

Ingresa un nombre y una edad para normalizarlos antes de mostrarlos.

Chilete DevPath explica: trim() elimina espacios externos, Number() convierte la edad y Number.isInteger() verifica que sea entera. Observa que transformar el nombre para mostrarlo no modifica el valor del campo.
