# Ruta de aprendizaje · Desarrollo web

| Nivel | Etapas | Resultado esperado |
|---|---|---|
| Base | 01–03 | Entender la web y crear documentos HTML semánticos con formularios y multimedia. |
| Maquetación | 04–07 | Controlar cascada, caja, posicionamiento, Flexbox, Grid, responsive y CSS moderno. |
| Interacción | 08–11 | Ejecutar JavaScript en navegador, modificar DOM, manejar eventos, asincronía, Fetch y Storage. |
| Aplicación | 12–14 | Usar Bootstrap con criterio, revisar accesibilidad/rendimiento e integrar un sitio completo. |

## Frontera con las siguientes etapas

- `08-patrones`: organización y patrones de diseño de software.
- `09-backend`: servidor, APIs, PHP/Spring/Node, autenticación y acceso a datos.
- `10-frontend`: frameworks, componentes, estado, routing y arquitectura frontend.
- `11-publicacion-y-produccion`: build, despliegue, dominio, DNS, HTTPS, CI/CD y operación.
