# Glosario

- **Cliente:** software que solicita un recurso o servicio; en esta etapa normalmente es el navegador.
- **Servidor:** sistema que recibe peticiones y devuelve recursos o datos.
- **HTTP/HTTPS:** protocolo de comunicación usado en la web; HTTPS añade cifrado mediante TLS.
- **HTML:** lenguaje de marcado que estructura el contenido.
- **CSS:** lenguaje que controla presentación y maquetación.
- **DOM:** representación en memoria del documento que JavaScript puede consultar y modificar.
- **Evento:** señal generada por una interacción o cambio, como `click`, `submit` o `input`.
- **Responsive:** diseño que se adapta a diferentes tamaños y capacidades de pantalla.
- **Fetch:** API del navegador para realizar peticiones HTTP asíncronas.
- **JSON:** formato textual para intercambiar datos estructurados.
- **Storage:** mecanismos de almacenamiento del navegador, como `localStorage` y `sessionStorage`.
- **Accesibilidad:** prácticas para que una interfaz pueda utilizarse por más personas y tecnologías de asistencia.
- **DevTools:** herramientas del navegador para inspeccionar HTML, CSS, JavaScript, red y almacenamiento.
