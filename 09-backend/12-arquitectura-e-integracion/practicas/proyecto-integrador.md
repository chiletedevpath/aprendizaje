# Proyecto integrador · API de capacitaciones

Diseña una API backend para gestionar trabajadores, cursos, inscripciones y certificaciones.

Debe incluir:
- contrato HTTP coherente;
- DTO y validación;
- reglas de negocio en servicios;
- persistencia relacional;
- transacciones;
- autenticación y roles;
- integración externa simulada;
- pruebas unitarias e integración;
- configuración mediante variables de entorno;
- justificación entre arquitectura por capas o hexagonal.

No requiere frontend ni despliegue productivo en esta etapa.
