# 07 · Diseño avanzado de APIs

Una API que crece necesita contratos predecibles para filtrar, paginar, evolucionar y documentar recursos.

**Aprenderás:** paginación, ordenamiento, filtros, PATCH, versionado, respuestas consistentes y OpenAPI.

**Reto:** diseña una consulta paginada de cursos con estado, texto de búsqueda y orden configurable.
