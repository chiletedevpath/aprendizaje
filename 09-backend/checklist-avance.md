# Checklist de avance · Backend

## HTTP y API
- [ ] Distingo método, ruta, headers, body y código de estado.
- [ ] Diseño recursos REST sin convertir acciones internas en URLs arbitrarias.
- [ ] Puedo justificar cuándo usar GET, POST, PUT, PATCH y DELETE.

## Spring
- [ ] Entiendo qué resuelven IoC y DI antes de usar anotaciones.
- [ ] Separo controlador, servicio y persistencia por responsabilidad.
- [ ] Utilizo DTO para contratos externos cuando corresponde.

## Persistencia
- [ ] Modelo relaciones JPA con criterio.
- [ ] Comprendo el límite de una transacción.
- [ ] Reconozco riesgos de lazy/eager y N+1 a nivel introductorio.

## Seguridad
- [ ] Distingo autenticación de autorización.
- [ ] No almaceno contraseñas en texto plano.
- [ ] No incluyo secretos en código, repositorio ni payload JWT.

## Calidad
- [ ] Pruebo casos normales, límites y errores.
- [ ] Sé diferenciar prueba unitaria e integración.
- [ ] Configuro logs sin exponer datos sensibles.

## Arquitectura
- [ ] Puedo explicar cuándo una estructura por capas es suficiente.
- [ ] Comprendo dominio, puertos y adaptadores en una arquitectura hexagonal.
- [ ] Puedo justificar decisiones sin añadir complejidad innecesaria.
