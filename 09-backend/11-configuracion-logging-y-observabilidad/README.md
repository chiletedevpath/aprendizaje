# 11 · Configuración, logging y observabilidad

La aplicación debe separar código de configuración y producir señales útiles para diagnosticar su estado.

**Aprenderás:** properties/YAML, profiles, variables de entorno, niveles de log, datos sensibles, health checks y Actuator introductorio.

**Reto:** separa configuración de desarrollo y pruebas sin incluir contraseñas reales en ningún archivo versionado.
