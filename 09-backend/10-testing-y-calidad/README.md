# 10 · Testing y calidad

Las pruebas verifican comportamiento esperado y protegen frente a regresiones. La cobertura es una señal, no una garantía de calidad.

**Aprenderás:** pruebas unitarias, mocks, integración, pruebas de controladores, casos límite, JaCoCo y calidad estática.

**Reto:** prueba un servicio que rechaza empresas duplicadas y crea correctamente una empresa nueva.
