# 01 · Fundamentos del backend

Un backend recibe una petición, ejecuta reglas y devuelve una respuesta. Antes de aprender Spring es necesario comprender esta responsabilidad sin framework.

**Aprenderás:** cliente/servidor, proceso, puerto, endpoint, estado, persistencia y separación frontend/backend/base de datos.

**Reto:** amplía el servidor mínimo para exponer `/salud` y `/cursos` con respuestas distintas.
