# 03 · Procesamiento del lado servidor

PHP se utiliza aquí como recurso complementario para observar de forma directa cómo el servidor recibe datos, mantiene sesión y consulta una base de datos.

**Aprenderás:** GET/POST, request, response, sesión, cookies, PDO y consultas preparadas.

Las prácticas de ciclos y arreglos se conservan por trazabilidad, pero esos conceptos ya pertenecen a Programación Básica.

Las prácticas PHP fueron trabajadas por Adrian Pisco en el curso Taller de Programación Web y se conservan aquí como evidencia de aprendizaje, no como proyecto académico final.

**Reto:** procesa un formulario de registro validando nombre y correo antes de producir la respuesta.
