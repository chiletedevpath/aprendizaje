# 08 · Integraciones externas y resiliencia

Un backend suele depender de proveedores externos. Esa dependencia debe mantenerse aislada y los fallos deben tratarse de forma explícita.

**Aprenderás:** clientes HTTP, DTO externos, Adapter, timeout, errores remotos, retry/circuit breaker como conceptos y fallback con criterio.

**Reto:** define cómo respondería tu aplicación si un proveedor de identidad excede el tiempo máximo de respuesta.
