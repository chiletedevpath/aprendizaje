# 02 · HTTP, REST, JSON y diseño de APIs

HTTP define cómo se intercambian solicitudes y respuestas. REST aporta criterios para modelar recursos sobre ese protocolo.

**Aprenderás:** métodos HTTP, códigos de estado, headers, path/query parameters, JSON, idempotencia y diseño de recursos.

**Reto:** diseña el contrato HTTP de una API de cursos con listar, consultar, registrar, actualizar parcialmente y eliminar.
