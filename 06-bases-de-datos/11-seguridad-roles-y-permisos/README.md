# 11 · Seguridad, roles y permisos

La seguridad de datos empieza por conceder únicamente los privilegios que una cuenta necesita.

## Qué debes dominar

- Usuarios y roles
- GRANT y REVOKE
- Mínimo privilegio
- Cuenta administrativa vs cuenta de aplicación
- Credenciales fuera del repositorio

## Reto del tema

Define un rol de consulta que pueda leer reportes pero no modificar tablas.

## Para avanzar

Aplicar mínimo privilegio y separar responsabilidades de administración y aplicación.

## Motores

Compara la implementación en `sql-server/`, `postgresql/` y `oracle/`. El concepto es común, pero el dialecto y las herramientas pueden cambiar.
