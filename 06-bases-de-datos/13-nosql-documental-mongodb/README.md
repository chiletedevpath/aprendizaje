# 13 · NoSQL documental con MongoDB

MongoDB almacena documentos. El diseño debe considerar qué datos se leen juntos y qué partes necesitan crecer de forma independiente.

## Qué debes dominar

- Documento y colección
- Embebido vs referencia
- CRUD
- Índices
- Aggregation pipeline

## Reto del tema

Modela cursos con recursos y etiquetas; consulta cursos activos agrupados por categoría.

## Para avanzar

Modelar documentos desde los patrones de acceso y trabajar CRUD, índices y agregaciones.
