# 12 · Respaldo, importación y migración

Las bases de datos deben poder recuperarse y trasladarse. Copiar archivos manualmente no equivale a un respaldo válido.

## Qué debes dominar

- Backup y restore
- Dump lógico
- CSV e importación
- Migración entre entornos
- Validación posterior

## Reto del tema

Describe un procedimiento seguro para exportar datos de prueba, restaurarlos y verificar conteos.

## Para avanzar

Comprender operaciones básicas para proteger, trasladar y recuperar información.

## Motores

Compara la implementación en `sql-server/`, `postgresql/` y `oracle/`. El concepto es común, pero el dialecto y las herramientas pueden cambiar.
