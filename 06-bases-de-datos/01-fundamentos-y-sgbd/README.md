# 01 · Fundamentos y SGBD

Una base de datos no es solo un archivo con registros. Es una representación persistente de información administrada por un SGBD.

## Qué debes dominar

- Dato, información y persistencia
- Base de datos y SGBD
- Esquema e instancia
- Modelos relacional, documental y columnas anchas
- Cliente, servidor y conexión

## Reto del tema

Explica qué responsabilidades pertenecen al SGBD y cuáles pertenecen a la aplicación.

## Para avanzar

Comprender qué problema resuelve una base de datos y diferenciar modelo, SGBD, esquema e instancia.
