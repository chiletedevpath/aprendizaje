# 06 · Consultas y filtrado

Consultar bien implica seleccionar solo los datos necesarios y expresar condiciones de forma clara.

## Qué debes dominar

- SELECT y alias
- WHERE
- ORDER BY y DISTINCT
- LIKE, IN, BETWEEN e IS NULL
- CASE y funciones básicas

## Reto del tema

Obtén productos con stock cuyo precio esté dentro de un rango, ordenados de mayor a menor y mostrando solo las columnas necesarias.

## Para avanzar

Recuperar datos con filtros, orden, condiciones y funciones sin depender de SELECT *.

## Motores

Compara la implementación en `sql-server/`, `postgresql/` y `oracle/`. El concepto es común, pero el dialecto y las herramientas pueden cambiar.
