# Checklist de avance

## Modelado
- [ ] Distingo modelo conceptual, lógico y físico.
- [ ] Defino cardinalidades y claves con una justificación.
- [ ] Detecto redundancia y anomalías antes de implementar tablas.
- [ ] Normalizo hasta 3FN cuando el problema lo requiere.

## SQL relacional
- [ ] Creo tablas con restricciones de integridad.
- [ ] Inserto, actualizo y elimino datos sin afectar filas no previstas.
- [ ] Construyo joins y agregaciones sin depender de `SELECT *`.
- [ ] Uso transacciones y explico qué cambia con `COMMIT` y `ROLLBACK`.
- [ ] Puedo justificar un índice y leer los elementos básicos de un plan de ejecución.
- [ ] Distingo vista, función, procedimiento y trigger.
- [ ] Aplico roles y permisos con mínimo privilegio.

## Operación
- [ ] Sé explicar la diferencia entre respaldo, restauración, exportación e importación.
- [ ] Reconozco que scripts de limpieza o migración pueden ser destructivos.

## NoSQL
- [ ] Modelo un documento MongoDB desde el patrón de acceso.
- [ ] Diseño una tabla Cassandra desde las consultas requeridas.
- [ ] No trato MongoDB y Cassandra como si compartieran el mismo modelo.

## Criterio
- [ ] Puedo explicar por qué elegiría una tecnología para un caso concreto.
- [ ] Utilizo datos ficticios y no guardo credenciales reales en el repositorio.
