# 03 · Modelo relacional y normalización

El modelo relacional transforma conceptos del dominio en relaciones con claves y dependencias controladas.

## Qué debes dominar

- Relación, tupla y atributo
- PK y FK
- Dependencias funcionales
- 1FN, 2FN y 3FN
- Anomalías y desnormalización justificada

## Reto del tema

Normaliza un registro de matrículas que repite estudiante, curso y docente hasta alcanzar 3FN.

## Ejemplo disponible

`ejemplos/modelo-logico-panaderia.puml` muestra cómo las relaciones N:M del modelo conceptual se convierten en tablas asociativas con claves primarias y foráneas.

## Para avanzar

Transformar un modelo conceptual en tablas coherentes y reducir redundancia mediante normalización.
