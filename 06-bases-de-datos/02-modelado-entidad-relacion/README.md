# 02 · Modelado entidad-relación

Antes de crear tablas se modela el dominio. El modelo ER permite discutir entidades y relaciones sin depender de un motor.

## Qué debes dominar

- Entidades y atributos
- Identificadores
- Cardinalidades 1:1, 1:N y N:M
- Participación y entidades débiles
- Reglas del dominio

## Reto del tema

Modela una biblioteca con autores, libros, ejemplares, usuarios y préstamos.

## Para avanzar

Representar entidades, atributos, relaciones, cardinalidades y restricciones antes de elegir un motor.
