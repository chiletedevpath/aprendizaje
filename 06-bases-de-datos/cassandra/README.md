# Apache Cassandra

**Estado:** pendiente de recepción, validación técnica y evaluación editorial.

Cassandra se estudiará como una base distribuida de columnas anchas, diseñada desde los patrones de consulta. No debe modelarse como si admitiera las mismas relaciones y uniones de un SGBD relacional.

## Cobertura prevista

- keyspaces y tablas;
- CQL básico;
- claves de partición y columnas de clustering;
- modelado orientado a consultas;
- consistencia y distribución a nivel introductorio;
- laboratorio reproducible con datos ficticios.

El contenido no se considera publicado ni validado hasta actualizar `../estado-publicacion.md`.
