# 07 · Joins, agrupaciones y consultas avanzadas

Las consultas avanzadas combinan relaciones, agregaciones y transformaciones para responder preguntas del negocio.

## Qué debes dominar

- INNER / LEFT / RIGHT / FULL JOIN
- GROUP BY y HAVING
- Subconsultas y EXISTS
- UNION / INTERSECT / EXCEPT
- CTE, ventanas y paginación

## Reto del tema

Resume los productos por categoría y muestra únicamente las categorías que superen una cantidad mínima de productos.

## Para avanzar

Relacionar tablas y construir consultas de análisis con agregaciones, CTE, conjuntos y ventanas.

## Motores

Compara la implementación en `sql-server/`, `postgresql/` y `oracle/`. El concepto es común, pero el dialecto y las herramientas pueden cambiar.
