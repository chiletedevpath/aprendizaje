# 14 · NoSQL de columnas anchas con Cassandra

En Cassandra el modelo parte de las consultas. La clave de partición y las columnas de clustering determinan distribución y orden.

## Qué debes dominar

- Keyspace y CQL
- Partition key
- Clustering columns
- Modelado por consulta
- Consistencia introductoria

## Reto del tema

Diseña una tabla para consultar avances de un estudiante por curso ordenados por fecha.

## Para avanzar

Diseñar tablas desde las consultas mediante particiones, clustering y CQL.
