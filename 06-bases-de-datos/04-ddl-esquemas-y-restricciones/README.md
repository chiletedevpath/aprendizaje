# 04 · DDL, esquemas y restricciones

DDL define la estructura que debe respetar la información. Las restricciones son parte del modelo, no decoración.

## Qué debes dominar

- CREATE / ALTER / DROP
- Tipos de datos
- PRIMARY KEY y FOREIGN KEY
- UNIQUE, NOT NULL, CHECK y DEFAULT
- IDENTITY, secuencias y columnas autogeneradas

## Reto del tema

Crea categorías y productos con claves, precio no negativo y stock no negativo.

## Para avanzar

Definir estructuras persistentes y proteger la integridad desde el esquema.

## Motores

Compara la implementación en `sql-server/`, `postgresql/` y `oracle/`. El concepto es común, pero el dialecto y las herramientas pueden cambiar.
