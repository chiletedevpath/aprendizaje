# 16 · Integración

La integración reúne modelado, implementación, consultas, seguridad, rendimiento y criterio tecnológico en un único caso.

## Qué debes dominar

- Modelo ER
- Esquema relacional
- Consultas y transacciones
- Índices y permisos
- Evaluación de una alternativa NoSQL

## Reto del tema

Construye el modelo de datos de un sistema de aprendizaje y documenta las decisiones principales.

Desarrolla el [laboratorio integrador del sistema de aprendizaje](laboratorio-sistema-aprendizaje.md) en uno de los motores relacionales y compara de forma argumentada una posible alternativa NoSQL.

## Para avanzar

Modelar e implementar una solución de datos de extremo a extremo y justificar las decisiones tomadas.
