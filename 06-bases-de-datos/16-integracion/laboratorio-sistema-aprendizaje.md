# Laboratorio integrador — Sistema de aprendizaje

Diseña la persistencia de una plataforma con:

- estudiantes;
- cursos;
- temas;
- matrículas;
- avances;
- recursos;
- evidencias de práctica.

## Entrega mínima

1. Modelo ER con cardinalidades justificadas.
2. Modelo relacional normalizado.
3. Implementación en un motor relacional.
4. Datos ficticios de prueba.
5. Cinco consultas: filtro, join, agrupación, subconsulta o CTE y ventana.
6. Una transacción que modifique más de una tabla.
7. Un índice justificado por una consulta frecuente.
8. Un rol de solo lectura para reportes.
9. Procedimiento de respaldo y restauración.
10. Análisis de qué parte, si alguna, podría beneficiarse de MongoDB o Cassandra.

## Evidencia esperada

- scripts ejecutables en orden conocido;
- casos de prueba y resultados obtenidos;
- versión del motor utilizado;
- explicación de restricciones, transacción, índice y permisos;
- comparación razonada entre el modelo relacional y la alternativa NoSQL.

## Criterio de logro

No se evalúa por cantidad de tablas. Se evalúa la coherencia entre requisitos, modelo, restricciones, consultas y tecnología elegida.
