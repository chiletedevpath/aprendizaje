# 05 · DML y CRUD

DML modifica el estado de la base. Cada operación debe identificar exactamente qué filas pretende afectar.

## Qué debes dominar

- INSERT
- UPDATE
- DELETE
- NULL
- Operaciones seguras con WHERE

## Reto del tema

Registra productos, cambia un precio y desactiva un producto sin borrar su historial.

## Para avanzar

Insertar, actualizar y eliminar datos de forma controlada.

## Motores

Compara la implementación en `sql-server/`, `postgresql/` y `oracle/`. El concepto es común, pero el dialecto y las herramientas pueden cambiar.
