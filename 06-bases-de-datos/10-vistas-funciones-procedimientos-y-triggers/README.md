# 10 · Vistas, funciones, procedimientos y triggers

Los objetos programables encapsulan consultas o comportamiento dentro del motor, pero su uso debe tener una razón clara.

## Qué debes dominar

- Vistas
- Funciones
- Procedimientos
- Triggers
- Diferencias de dialecto

## Reto del tema

Crea una vista de productos activos y una operación programable que actualice stock de forma controlada.

## Para avanzar

Encapsular consultas y lógica cercana a los datos reconociendo diferencias entre motores.

## Motores

Compara la implementación en `sql-server/`, `postgresql/` y `oracle/`. El concepto es común, pero el dialecto y las herramientas pueden cambiar.
