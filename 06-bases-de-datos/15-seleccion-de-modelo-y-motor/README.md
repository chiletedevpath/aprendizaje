# 15 · Selección de modelo y motor

No existe un motor universal. La elección debe responder a consistencia, relaciones, volumen, latencia y patrones de acceso.

## Qué debes dominar

- Relacional vs documental vs columnas anchas
- Consistencia y transacciones
- Flexibilidad de esquema
- Escalabilidad y distribución
- Costo operativo y experiencia del equipo

## Reto del tema

Compara tres casos y justifica una elección tecnológica para cada uno.

## Para avanzar

Elegir una tecnología por requisitos de consistencia, relaciones, volumen, distribución y patrones de acceso.
