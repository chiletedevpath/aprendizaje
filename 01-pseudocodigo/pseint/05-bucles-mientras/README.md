## Uso recomendado

1. Intenta anticipar la salida antes de ejecutar.
2. Identifica entradas, proceso y salidas.
3. Ejecuta el algoritmo en PSeInt.
4. Cambia los datos y prueba un caso límite.
5. Explica qué estructura controla la solución.
