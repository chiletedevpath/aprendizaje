# Práctica autónoma

Esta carpeta reúne la práctica que debe intentarse **sin consultar primero una solución**. El propósito es transformar los conceptos de la guía didáctica en evidencia propia.

## Organización

| Recurso | Propósito |
|---|---|
| [`retos/`](retos/README.md) | Siete problemas, uno por bloque de aprendizaje. |
| [`soluciones/`](soluciones/README.md) | Soluciones de referencia para comparar después del primer intento. |
| [`laboratorios/`](laboratorios/README.md) | Evidencia integradora de cierre del módulo. |

## Método recomendado

1. Estudia el bloque correspondiente en [`../guia-didactica.md`](../guia-didactica.md).
2. Resuelve el reto sin mirar la solución.
3. Define resultados esperados antes de ejecutar.
4. Prueba casos normales, límite e inválidos.
5. Corrige tu algoritmo.
6. Recién entonces compara con la solución de referencia.
7. Explica las diferencias con tus propias palabras.

> La solución de referencia no representa una única forma válida de resolver el problema.
