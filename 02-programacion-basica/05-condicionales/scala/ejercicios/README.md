# Ejercicios · Condicionales · Scala

## Cómo trabajar

1. Resuelve primero el enunciado sin mirar otro archivo.
2. Define entrada, proceso y salida.
3. Ejecuta al menos un caso normal y uno límite.
4. Si existe entrada del usuario, añade un caso inválido.
5. Después compara tu solución con los ejercicios resueltos disponibles en esta carpeta.

## Retos propuestos

1. Clasifica una nota validando primero el rango.
2. Calcula un descuento según tramos de compra.
3. Implementa una selección de menú usando `switch` en Java y `match` en Scala.

## Nota

Los archivos de código presentes junto a este README son prácticas resueltas. No necesitas que tu solución sea idéntica: debe cumplir el requerimiento, manejar los límites y poder explicarse con claridad.
