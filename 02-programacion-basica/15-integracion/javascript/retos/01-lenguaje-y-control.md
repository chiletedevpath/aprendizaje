# Retos: lenguaje y control

Resuelve cada reto con datos ficticios y registra al menos un caso normal y uno límite.

1. Crea una ficha de recurso con título, duración, disponibilidad y nivel. Imprime valor y tipo de cada dato; después explica cuáles deberían ser constantes.
2. Calcula el avance porcentual de una ruta y clasifícalo como pendiente, en progreso o completado. Controla valores menores que 0 y mayores que 100.
3. Normaliza el título de un recurso: elimina espacios exteriores, unifica mayúsculas y genera un identificador con guiones.
4. Recorre una colección de duraciones y calcula total, promedio, mínimo y máximo sin modificar la colección original.
5. Construye un menú textual con `switch` para seleccionar HTML, CSS o JavaScript. Incluye una opción desconocida.

## Evidencia

Explica qué operadores y estructuras elegiste, y por qué un caso límite no rompe el resultado.
