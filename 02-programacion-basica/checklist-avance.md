# Checklist de avance

Marca una etapa como completada cuando puedas demostrarla con código propio.

- [ ] Configuro y ejecuto programas sencillos en Java y Scala.
- [ ] Distingo variables, constantes, tipos y conversiones.
- [ ] Construyo expresiones aritméticas, relacionales y lógicas.
- [ ] Uso condicionales y bucles según el problema.
- [ ] Creo funciones o métodos con parámetros y retorno.
- [ ] Manipulo cadenas, arreglos, matrices y colecciones básicas.
- [ ] Valido entradas y manejo errores previsibles.
- [ ] Leo y escribo archivos de texto sencillos.
- [ ] Uso la biblioteca estándar antes de reinventar una utilidad existente.
- [ ] Divido una solución en responsabilidades pequeñas.
- [ ] Pruebo casos normales, límite e inválidos.
- [ ] Puedo explicar una solución sin leer el código línea por línea.
- [ ] Completo el reto integrado sin adelantar conceptos de POO.
