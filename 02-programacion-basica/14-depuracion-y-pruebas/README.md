# Depuración y pruebas básicas

**Nivel:** Intermedio

Localizar defectos con evidencia y verificar resultados antes de considerar una solución terminada.

## Lo esencial

- trazado de variables
- breakpoints
- casos normales
- casos límite
- casos inválidos
- resultado esperado vs. obtenido

## Cómo trabajar este tema

1. Revisa primero los ejemplos del lenguaje que estés estudiando.
2. Ejecuta las prácticas y cambia valores para observar el comportamiento.
3. Resuelve el reto sin abrir `soluciones/`.
4. Compara después tu enfoque con la solución de referencia en Java o Scala.

## Reto

Implementa una función que determine si un número es par y verifica al menos cinco casos, incluidos cero y números negativos.

**Comprobación mínima:** prueba un caso normal, un caso límite y, cuando corresponda, una entrada inválida.
