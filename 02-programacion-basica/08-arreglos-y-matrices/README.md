# Arreglos y matrices

**Nivel:** Básico avanzado

Guardar colecciones de tamaño fijo y recorrer datos organizados en una o dos dimensiones.

## Lo esencial

- índices
- recorridos
- búsqueda
- acumulación
- matrices
- arreglos paralelos

## Cómo trabajar este tema

1. Revisa primero los ejemplos del lenguaje que estés estudiando.
2. Ejecuta las prácticas y cambia valores para observar el comportamiento.
3. Resuelve el reto sin abrir `soluciones/`.
4. Compara después tu enfoque con la solución de referencia en Java o Scala.

## Reto

Registra cinco notas en un arreglo y muestra promedio, nota mayor, nota menor y cantidad de aprobados.

**Comprobación mínima:** prueba un caso normal, un caso límite y, cuando corresponda, una entrada inválida.
