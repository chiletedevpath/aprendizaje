# Retos JavaScript: funciones

1. Implementa una función que reciba recursos y devuelva únicamente los publicados sin alterar el arreglo original.
2. Implementa funciones separadas para validar, agregar, buscar y retirar recursos.

Prueba entradas vacías, códigos duplicados y códigos ausentes. Cada función debe tener una responsabilidad, entrada y salida identificables; evita imprimir dentro de funciones que deben devolver un resultado reutilizable.
