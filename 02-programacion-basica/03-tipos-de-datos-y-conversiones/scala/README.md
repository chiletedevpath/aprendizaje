# Tipos de datos y conversiones · Scala

## En este lenguaje

`Int`, `Double`, `Boolean`, `Char`, `String` y conversiones como `toInt` o `toDouble`.

## Ejemplo guiado

Abre [`ejemplos-guiados`](./ejemplos-guiados/). El ejemplo contiene comentarios únicamente en los puntos donde ayudan a comprender una decisión técnica.

Al leerlo identifica:

1. los datos de entrada;
2. la transformación principal;
3. el resultado;
4. la sintaxis específica de Scala;
5. el concepto que seguiría existiendo en otro lenguaje.

## Ejercicios

Consulta [`ejercicios/README.md`](./ejercicios/README.md). Los archivos de código, cuando existen, son prácticas resueltas; los retos del README están pensados para resolverse sin copiar el ejemplo.

## Ejecución

Los ejemplos usan Scala 3. Puedes ejecutarlos desde un proyecto `sbt` o con Scala CLI.

## Comparación

Scala permite expresar varios resultados como expresiones y favorece valores inmutables con `val`.
