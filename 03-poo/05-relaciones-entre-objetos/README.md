# Relaciones entre objetos

Los objetos colaboran mediante asociación, dependencia, agregación o composición según su ciclo de vida y responsabilidad.

## Qué debes dominar

- identificar cuándo usar este concepto;
- reconocerlo en código;
- explicarlo con tus propias palabras;
- aplicarlo sin introducir complejidad innecesaria.
