# Checklist de avance · POO

Antes de pasar a `04-estructuras-datos`, verifica que puedes:

- [ ] diferenciar clase, objeto, atributo, método y estado;
- [ ] crear objetos con constructores coherentes;
- [ ] proteger invariantes mediante encapsulamiento;
- [ ] elegir entre asociación, composición y herencia;
- [ ] explicar por qué una jerarquía representa una relación “es un”;
- [ ] aplicar sobrescritura y polimorfismo sin condicionales por tipo;
- [ ] usar abstracciones, interfaces o traits cuando existe un contrato común;
- [ ] diferenciar miembros de clase y de instancia;
- [ ] explicar `toString`, `equals` y `hashCode` en Java;
- [ ] usar enum y genéricos en casos simples;
- [ ] crear una excepción propia del dominio;
- [ ] interpretar un diagrama UML de clases básico;
- [ ] identificar responsabilidades, cohesión y acoplamiento;
- [ ] construir una práctica integradora y justificar sus decisiones.
