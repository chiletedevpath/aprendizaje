# Clases y objetos

Una clase define un tipo; un objeto es una instancia concreta creada a partir de esa definición.

## Qué debes dominar

- identificar cuándo usar este concepto;
- reconocerlo en código;
- explicarlo con tus propias palabras;
- aplicarlo sin introducir complejidad innecesaria.

## Reto

Crea una clase `Curso` con título y duración. Instancia dos cursos y muestra sus datos.

Empieza con `java/ejemplos` o `scala/ejemplos`, revisa `practicas` y consulta `soluciones` solo después de intentar el reto.
