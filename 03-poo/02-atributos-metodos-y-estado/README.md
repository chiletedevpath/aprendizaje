# Atributos, métodos y estado

Los atributos representan estado; los métodos consultan o modifican ese estado mediante comportamiento definido.

## Qué debes dominar

- identificar cuándo usar este concepto;
- reconocerlo en código;
- explicarlo con tus propias palabras;
- aplicarlo sin introducir complejidad innecesaria.

## Reto

Crea `Contador` con estado interno y métodos `incrementar()` y `mostrarValor()`.

Empieza con los ejemplos del lenguaje que estés estudiando, revisa `practicas` y consulta `soluciones` solo después de intentar el reto. La práctica de JavaScript encapsula las notas y el cálculo del promedio dentro de `Estudiante`.
