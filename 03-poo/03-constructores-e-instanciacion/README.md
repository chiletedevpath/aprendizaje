# Constructores e instanciación

Un constructor prepara el estado inicial del objeto y permite exigir datos desde el momento de creación.

## Qué debes dominar

- identificar cuándo usar este concepto;
- reconocerlo en código;
- explicarlo con tus propias palabras;
- aplicarlo sin introducir complejidad innecesaria.
