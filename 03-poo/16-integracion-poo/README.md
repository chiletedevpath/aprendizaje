# Integración POO

La integración combina modelado, encapsulamiento, relaciones, polimorfismo y validaciones en un problema completo.

## Qué debes dominar

- identificar cuándo usar este concepto;
- reconocerlo en código;
- explicarlo con tus propias palabras;
- aplicarlo sin introducir complejidad innecesaria.

## Reto

Construye un sistema pequeño de cursos, participantes e inscripciones. Incluye UML y casos de prueba.

Empieza con `java/ejemplos` o `scala/ejemplos`, revisa `practicas` y consulta `soluciones` solo después de intentar el reto.

## Laboratorio integrador

Después del reto completa [`laboratorio-ruta-aprendizaje.md`](./laboratorio-ruta-aprendizaje.md). No se incluye una solución para que el resultado evidencie tus propias decisiones de modelado.
