# Origen de las prácticas

Las prácticas Java reutilizadas en esta reorganización provienen del módulo `03-poo` original de Chilete DevPath y corresponden al proceso de aprendizaje del autor.

La reorganización no convierte esas prácticas históricas en “ejemplos guiados”. Los nuevos archivos de `ejemplos/` siguen el estándar editorial actual: código pequeño, ejecutable y comentarios breves que explican decisiones o conceptos técnicos.
