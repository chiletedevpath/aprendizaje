# Sobrescritura y polimorfismo

La sobrescritura adapta un comportamiento heredado; el polimorfismo permite invocarlo mediante un tipo común.

## Qué debes dominar

- identificar cuándo usar este concepto;
- reconocerlo en código;
- explicarlo con tus propias palabras;
- aplicarlo sin introducir complejidad innecesaria.

## Reto

Modela dos tipos de notificación y procésalos desde una referencia común sin preguntar por su clase concreta.

Empieza con `java/ejemplos` o `scala/ejemplos`, revisa `practicas` y consulta `soluciones` solo después de intentar el reto.
